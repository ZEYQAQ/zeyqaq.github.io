### 2.2 镜像迁移（跨区 SWR）

**关键挑战**：将国内镜像仓库中指定业务模块的全量镜像（含所有 Tag）迁移至海外镜像仓库。

自研批量迁移脚本，核心逻辑如下：

```bash
#!/bin/bash
# 跨区镜像迁移脚本（脱敏示意）

SRC_REG="swr.{国内区域}.example.com"
DST_REG="swr.{海外区域}.example.com"
KEYWORD="目标业务模块关键字"

# 1. 查询源仓库中含关键字的镜像列表
# 2. 遍历每个镜像的所有 Tag
# 3. 使用 skopeo copy 直接跨仓库推送，无需本地落盘
for REPO in $REPOS; do
  for TAG in $TAGS; do
    skopeo copy \
      --src-creds  "${SRC_USER}:${SRC_PASS}" \
      --dest-creds "${DST_USER}:${DST_PASS}" \
      "docker://${SRC_REG}/${SRC_ORG}/${REPO}:${TAG}" \
      "docker://${DST_REG}/${DST_ORG}/${REPO}:${TAG}"
  done
done
```

> **技术亮点**：使用 `skopeo` 直接完成仓库间 Copy，避免先 pull 再 push 的本地存储消耗，速度更快，适合大批量镜像迁移场景。
