本人角色：基础设施负责人，独立完成从云资源规划到服务上线的全流程。

时间：2026-05-14～2026-05-20

二、服务迁移

2.1 导出原有集群 YAML

2.2 镜像迁移（跨区 SWR）

关键挑战：将国内镜像仓库中指定业务模块的全量镜像（含所有 Tag）迁移至海外镜像仓库。

自研批量迁移脚本，核心逻辑如下：

#!/bin/bash
# 跨区镜像迁移脚本（脱敏示意）

SRC_REG="swr.{国内区域}.example.com"
DST_REG="swr.{海外区域}.example.com"
KEYWORD="目标业务模块关键字"

# 1. 查询源仓库中含关键字的镜像列表
# 2. 遍历每个镜像的所有 Tag
# 3. 使用 skopeo copy 直接跨仓库推送，无需本地落盘
for REPO in $REPOS; do
  for TAG in $TAGS; do
    skopeo copy \
      --src-creds  "${SRC_USER}:${SRC_PASS}" \
      --dest-creds "${DST_USER}:${DST_PASS}" \
      "docker://${SRC_REG}/${SRC_ORG}/${REPO}:${TAG}" \
      "docker://${DST_REG}/${DST_ORG}/${REPO}:${TAG}"
  done
done

技术亮点：使用 skopeo 直接完成仓库间 Copy，避免先 pull 再 push 的本地存储消耗，速度更快，适合大批量镜像迁移场景。

2.3 YAML 适配改造

迁移后的 YAML 需适配新集群环境，编写脚本完成批量替换：

  2. PVC 名称替换：将旧 PVC 引用批量替换为新建的海外 PVC 名称
  3. 镜像地址二次修正：修正部分工作负载中组织路径层级不一致问题
bash 03_patch_images.sh    # 修改镜像地址
bash 02_apply_to_sg.sh     # 应用到新集群

在新集群通过 kubectl 批量创建工作负载和 Service，完成后进行逐一 Pod 状态巡检。

三、网络与入口配置

3.1 ELB 配置

新建负载均衡器，完成监听器与后端服务器组配置：

  • 启用 HTTP/2（业务使用 SSE，不依赖 WebSocket）
  • 配置健康检查策略

3.2 批量更新 SVC 绑定 ELB

编写脚本将所有 LoadBalancer 类型的 Service 统一指向新 ELB（包括 ELB ID 与内网 IP 注入）：

bash 06_patch_svc_elb.sh

3.3 Nginx 安装与配置

五、镜像管理

5.1 批量重部署

编写 replicas.sh 脚本，完成所有工作负载的滚动重启（触发镜像拉取最新版本）：

5.2 最新生产镜像推送

将最新构建版本的镜像 Tag 推送至海外镜像仓库，并更新对应 Deployment 的镜像版本：

docker tag {源镜像}:{tag} {海外仓库}/{组织}/{镜像名}:{tag}
docker push {海外仓库}/{组织}/{镜像名}:{tag}
